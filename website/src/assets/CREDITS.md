# Decorative game artwork

`log2-canyon.png` is the Canyon background from **Dragon Ball Z: The Legacy of Goku II**, credited to contributor **Son Gohan** by [Sprite Database](https://spritedatabase.net/file/2915). The original game graphics belong to their original creators and rights holders; this asset is not original Hub artwork and is not covered by the Hub code license.

The owner explicitly authorized authentic trilogy game assets for this noncommercial fan site during LOG-HUB-004C. This is ambient interface scenery, never a submitted project's cover or screenshot. No ROM file is included. The source PNG is unchanged. CSS uses native 256px scaling on mobile and 512px integer scaling on desktop, preserving square pixels and aspect ratio.

`sources.json` records the exact source page/image URL, dimensions, byte size and SHA-256. The asset is self-hosted through Astro/Vite and requires no external runtime request. No raw sprite archive, unrelated artwork, or obsolete DragonByte screenshot is included.
