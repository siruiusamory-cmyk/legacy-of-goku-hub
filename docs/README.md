# Documentation

[Visit the Hub](https://legacyofgokuhub.com/) · [Submit a project](https://legacyofgokuhub.com/submit/) · [Contribute](../CONTRIBUTING.md)

For community members, project submissions and corrections are handled through the public website. You do not need a GitHub account.

For developers, the [manifest schema](../schema/manifest.schema.json) and [example](../examples/.loghub.json) describe optional repository-based submissions.

For maintainers, the source and operating references are:

- [Content moderation](moderation.md)
- [Publication, backups and recovery](OPERATIONS.md)
- [Administration](launch/ADMIN.md)
- [Submissions service](launch/SUBMISSIONS.md)
- [Ratings service](launch/RATINGS.md)
- [Cloudflare configuration](launch/CLOUDFLARE.md)
- [Deployment and rollback](launch/DEPLOYMENT.md)

Historical proposals, design screenshots and milestone reports are not maintained in the current source tree. They remain available through Git history. The live configuration and signed publication state, not old development notes, determine production status.
